## ประเด็นที่ยังเปิดอยู่

1. **ลำดับขาบัซเซอร์ H2** เดินเป็น `GND / GPIO14 / 5V` ยังไม่ได้เทียบกับโมดูลจริง ถ้าโมดูลเรียงกลับด้าน โมดูลพังตอนเสียบ ต้องเช็คก่อนเสียบ
2. **IR LED ใน BOM** TSAL6200 เป็น 940 nm (Vishay doc 81010) ไม่ใช่ 850 nm ตามที่เอกสารเก่าเขียน ถ้าต้องการ 850 nm ใช้ TSHG6400 แทน เป็น through-hole เปลี่ยนเองได้
3. **IR-cut filter ของกล้อง** ยังทดสอบไม่จบ ถ้ากล้องมีฟิลเตอร์ IR LED จะไม่มีผล ใช้ `firmware/DrowsinessDiag` ทดสอบ
4. **อุณหภูมิ** ชิปรับได้ถึง 65°C แต่ในรถกลางแดดถึง 70–80°C ต้องถอดเก็บเมื่อจอด
