### การวางโมดูล ESP32-S3-CAM

- เสียบหงาย กล้องหันขึ้น ปลาย USB หันขอบบนของบอร์ด (ตามลูกศรบน silkscreen)

- ตอนเสียบสายคอมเข้าพอร์ต USB ของโมดูล ให้เลื่อน SW1 ไปที่ OFF ก่อน (ขา 5V ของโมดูลต่อตรงกับราง 5V ของบอร์ด)

## ประเด็นที่ยังเปิดอยู่

1. **โมดูล buzzer จริง** ยังไม่ได้ดูว่าใช้ทรานซิสเตอร์ PNP หรือไม่ ถ้าไม่ใช่ เสียงที่ไฟ 3V3 อาจเบากว่าเดิม และต้องเช็คลำดับขาก่อนเสียบ
2. **ไฟเขียว LED1 หรี่** R11 = 470Ω ได้กระแส ~1 mA ถ้าต้องการให้สว่างขึ้น เปลี่ยนเป็น 120Ω ตอนบัดกรีได้
3. **IR LED ใน BOM** TSAL6200 เป็น 940 nm (Vishay doc 81010) ไม่ใช่ 850 nm ถ้าต้องการ 850 nm ใช้ TSHG6400 แทน เป็น through-hole เปลี่ยนเองได้
4. **IR-cut filter ของกล้อง** ยังทดสอบไม่จบ ถ้ากล้องมีฟิลเตอร์ IR LED จะไม่มีผล ใช้ `firmware/DrowsinessDiag` ทดสอบ
5. **อุณหภูมิ** ชิปรับได้ถึง 65°C แต่ในรถกลางแดดถึง 70–80°C ต้องถอดเก็บเมื่อจอด
