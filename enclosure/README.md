# กล่อง 3D

แบบร่าง 3D ดูได้ที่ https://claude.ai/artifact/W44j3wrijPSJBLZRLcjgHY (ยังใช้ขนาดโมดูลแบบเดาไว้ก่อนวัดของจริง ต้องแก้ตามข้อมูลด้านล่าง)

## ข้อกำหนด (บอร์ด v2)

- บอร์ด 58.55 × 73.03 มม. รู M3 สี่มุมที่ (11.2, −19.5), (61.8, −19.5), (11.2, −84.5), (61.8, −84.5) และ MOUNT1 Ø7.5 ที่ (36.4, −83.2)
- โมดูล ESP32-S3-CAM กว้าง ~31 มม. ลอยเหนือบอร์ด ~8.5 มม. (ความสูง header) ปลาย USB เสมอแถวขาบนสุด ปลายฝั่ง 3V3 ยื่นเลยแถวขาล่าง ~10 มม. (กว้าง ~20 มม. เป็นเสาอากาศ)
- กล้องอยู่บนฝาโลหะของ ESP32 ศูนย์กลางราว (35.5, −58) ตัวกล้อง ~9.5 มม.
- ชิ้นที่สูงที่สุดบนบอร์ด (ไม่นับโมดูล) ~8.6 มม. คือ IR LED, header และก้าน SW1 (~7.8 มม.)
- **วัสดุ: PETG หรือ ASA** ห้ามใช้ PLA กับตัวจริง เพราะ PLA นิ่มที่ 55–60°C แต่ในรถร้อนถึง 70–80°C

| ชิ้น | ตำแหน่ง (มม.) | ต้องเว้น |
|---|---|---|
| กล้อง | (35.5, −58) | ช่องเปิดตรงๆ ไม่มีแผ่นใสบัง + ช่องรัดตัวกล้องใต้ฝา |
| IR1–IR4 | x = 61, y = −28 / −42 / −56 / −70 | รู Ø5.2 + ท่อกั้นแสงรั่วเข้ากล้อง |
| LDR (R2) | (12.8, −46.9) | รูให้แสงเข้า |
| LED1 / LED2 | (48.4, −73.5) / (53.7, −73.4) | light pipe (ไม่โดนโมดูลบัง) |
| USB1 (USB-C รับไฟ) | (10.9, −32.9) ขอบซ้าย | ช่องเสียบ + กันสายโยก |
| พอร์ต USB ของโมดูล | ปลายบนของโมดูล ใกล้ขอบบนบอร์ด | ช่องที่ผนังบนสำหรับแฟลช |
| SW1 สวิตช์ไฟ | (14.7, −78) ก้านชี้ขึ้น | ช่องบนฝา + ด้ามต่อสวมก้าน |
| H1 OLED / H2 buzzer | (12.6, −57.5) / (14.1, −24.5) | ต่อสาย Dupont ไปจอและ buzzer ที่ยึดไว้ใต้ฝา |

**ยังต้องวัด:** ขนาด OLED (แผ่น PCB, ระยะรู, ขนาดจอ) และโมดูล buzzer

ติดตั้งในรถด้วยน็อตเกลียว 1/4"-20 หรือขาแบบ GoPro ที่ฐาน แล้วใช้ขาจับมือถือในรถที่มีขาย
