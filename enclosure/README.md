# กล่อง 3D

ยังไม่ได้ออกแบบ ไฟล์ CAD และ STL จะเก็บในโฟลเดอร์นี้

## ข้อกำหนด

- บอร์ด 58.55 × 65.66 มม. ไม่มีรู M3 มีแค่ MOUNT1 Ø7.5 มม. ที่ (33.4, −75.9) จับบอร์ดด้วยรางขอบ, snap หรือใช้ MOUNT1
- โมดูล ESP32-S3-CAM ลอยเหนือบอร์ด ~8.5 มม. (ความสูง header) ยาวราว 67 มม. ยื่นเลยขอบบอร์ดด้านบน
- **วัสดุ: PETG หรือ ASA** ห้ามใช้ PLA กับตัวจริง เพราะ PLA นิ่มที่ 55–60°C แต่ในรถร้อนถึง 70–80°C

| ชิ้น | ตำแหน่ง (มม., จาก PickAndPlace) | ต้องเว้น |
|---|---|---|
| กล้อง | บนโมดูล วัดจากของจริง | ช่องเปิดตรงๆ ไม่มีแผ่นใสบัง |
| IR1–IR4 | x = 61, y = −28 / −42 / −56 / −70 | รู Ø5.2 และผนังกั้นแสงรั่วเข้ากล้อง |
| LDR (R2) | (12.8, −46.9) | รูให้แสงเข้า |
| LED1 / LED2 | (48.4, −73.5) / (53.7, −73.4) | light pipe หรือรูเล็ก |
| USB1 (USB-C) | (10.9, −32.9) ขอบซ้าย | ช่องเสียบ + กันสายโยก |
| SW1 สวิตช์ไฟ | (14.7, −78) | ช่องเลื่อนสวิตช์ |
| H1 OLED / H2 buzzer | (12.6, −57.5) / (12.4, −22.7) | หน้าต่าง OLED และรูเสียง |
