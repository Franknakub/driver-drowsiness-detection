# แบบเสนอกล่อง v0 (17 ต.ค. 2026) — รออนุมัติ ยังไม่ได้ทำ CAD

ค่าทั้งหมดอ้าง `DESIGN_INPUTS.md` · พิกัดบอร์ด x/y/z แบบเดียวกัน (บรรยายในแนวตั้ง USB ขึ้น แต่ติดตั้งจริงจะหมุน 90°)

## สิ่งที่ผู้ใช้ตัดสินแล้ว (17 ต.ค.)
- ตำแหน่งติดตั้ง: **ทดสอบในรถก่อน** → กล่องใช้ขาเกลียว 1/4"-20 กับขาจับมือถือแบบปรับมุมได้ ย้ายจุดทดสอบได้
- ทิศกล่อง: **วางให้ภาพจากกล้องตั้งตรง** (firmware ไม่ต้องหมุนภาพ) → กล่องแนวนอน · ทิศหมุน (ตามหรือทวนเข็ม) ยืนยันด้วยภาพสด rot 0 ก่อนทำ CAD ห้ามเดา
- ปริ้น: **ส่งร้าน/ฝากปริ้น** → ส่ง STL + ค่าตั้งปริ้น (PETG/ASA ดำ)
- CAD: **Claude เขียนสคริปต์ build123d** → ได้ STEP + STL
- เดิม: power bank นอกกล่อง · OLED หันด้านเดียวกับกล้อง
- **18 ต.ค. ขาติดตั้ง = ขาดูดกระจกแบบกล้องหน้ารถ** เกลียว 1/4"-20 แป้น Ø30.36 · หลังกล่องหันกระจก · จุดขันกลางแนวยาวเยื้องไปฝั่ง IR (ดู README หัวข้อขาติดตั้ง) → หลังกล่องหนาขึ้น 6 มม. กล่องลึกรวม 36.7

## ผังรวม

```
        ผนังบน: ช่องเสียบ USB โมดูล 2 ช่อง (แฟลช) + ช่องระบาย
  ┌──────────────────────────────────────────┐
  │ H2  ┌─────── โมดูล ESP32-S3-CAM ───────┐  ○ IR1 │  ← ฝาหน้า (หันหาคนขับ)
 [USB1] │  BOOT●          ●RST            │        │
  │ LDR │                                 │  ○ IR2 │   ○ = ท่อกั้นแสง IR ถึงผิวฝา
  │ H1  │          ◎ กล้อง (ช่องกรวย 120°) │  ○ IR3 │
  │     │        (เสาอากาศ — ห้ามโลหะ)     │  ○ IR4 │
  │ SW1 └─────────────────────────────────┘ LED1 LED2
  ├──────────────────────────────────────────┤
  │   ┌──── OLED 0.96″ ────┐   ┌ buzzer ┐    │  ← ส่วนต่อขยาย ~30 มม.
  │   │   หน้าต่างจอ        │   │ รูเสียง │    │
  │   └────────────────────┘   └────────┘    │
  └──────────────────────────────────────────┘
```

**ขนาดภายนอกโดยประมาณ ~64 × 108 × 29 มม.** (ติดตั้งแนวนอน = กว้าง 108 สูง 64 หนา 29) → ฉบับร่าง CAD ได้ **64.5 × 114.9 × 30.7** (ส่วนต่อขยายต้องยาวพอให้ buzzer 32 มม. วางแนวตั้ง · ฝาสูงขึ้นให้ตัวกล้องอยู่ใต้ผิวในฝา)

**ทำไมจอกับ buzzer อยู่ส่วนต่อขยายใต้บอร์ด:** แถบซ้ายของบอร์ดกว้างแค่ ~13 มม. (USB1, LDR, H1, SW1) แถบขวามี IR · เหนือโมดูลวางไม่ได้เพราะบังกล้องและอยู่ใกล้เสาอากาศ · ขอบล่างบอร์ดไม่มีอะไรยื่น สาย dupont จาก H1/H2 อ้อมขอบซ้ายลงมาได้

## หน้าตัดความสูง (z จากพื้นกล่อง)

| ชั้น | z (มม.) | ที่มา |
|---|---|---|
| พื้นกล่อง (ฐาน) | 0 – 2.0 | ผนัง 2 มม. |
| เสารองบอร์ด | 2.0 – 6.0 | ขาใต้บอร์ด `bot_h` 2.6 + เผื่อ 1.4 |
| PCB | 6.0 – 7.69 | `pcb_t` 1.69 |
| ยอดเลนส์ | 28.35 | `st_lens` 20.66 ⚠️ ค่าขัดกัน (C2) |
| ผิวนอกฝา | ~28.85 | เลนส์ต่ำกว่าผิวฝา 0.5 → ภาพไม่ติดขอบ |

## รายละเอียดแต่ละจุด

| จุด | แบบ |
|---|---|
| **แบ่งชิ้น** | 2 ชิ้น: **ฐาน** (ถาดตื้น + เสารองบอร์ด + น็อต 1/4"-20) และ **ฝาหน้า** (ผนังทั้งหมด + ทุกช่อง) · รอยต่อที่ระดับใต้ PCB → ช่องที่ผนังเป็นร่องเปิดด้านรอยต่อ ปริ้นได้ไม่ต้องมี support |
| **ปิดกล่อง** | น็อต M3 สอดจากหลังฐาน ผ่านเสา → รู MH1–MH4 → เข้า heat-set insert ในเสาของฝา (เสาฝากดบอร์ดลงบนเสาฐาน = หนีบบอร์ดด้วย) + น็อต M3 อีก 2 ตัวที่มุมส่วนต่อขยาย · รวม 6 ตัว · เสา MH ทั้ง 4 ห่างเสาอากาศ > 12 มม. |
| **ช่องกล้อง** | รูเปิดโล่ง ไม่มีแผ่นใส · ผนังรูบานเป็นกรวย 120° · มีปลอกสั้นจากใต้ฝาลงไปรอบกระบอกเลนส์ กันแสงในกล่องสะท้อนเข้า |
| **ท่อ IR** | ท่อดำในตัว Ø6.3 (ปีก 5.9 + เผื่อ) ผนัง 2 มม. จากผิวฝาลงไปห่างผิว PCB 0.5 มม. · LED อยู่ลึกจากผิวฝา ~19.5 มม. ท่อจำกัดลำแสงราว ±18° ใกล้มุมของ TSAL6200 (±17°) จึงไม่เสียแสง |
| **LDR** | ท่อ Ø5 ปากบานเป็นกรวย ตรงลงไปที่ LDR (ลึก ~24 มม. รับแสงเป็นกรวยแคบ) |
| **LED1/LED2** | แท่งอะคริลิกใส Ø3 (ซื้อ) สอดในรูของฝา ปลายล่างห่าง LED ~0.5 มม. · ⚠️ LED1 อยู่ห่างปลายเสาอากาศแค่ ~1.4 มม. แท่ง Ø3 อาจชนโมดูล → ต้องวัด `mod_bot` ก่อน (ดูคำถามด้านล่าง) |
| **USB1 รับไฟ** | ช่องที่ผนังซ้ายพอดีหัวสาย USB-C + เผื่อ 0.5 · ขนาดรอวัดหัวสายจริง (ขั้น 7) · ร่องรัดสายด้วยเคเบิลไทร์ที่ฐาน กันสายโยกดึงพอร์ต |
| **USB โมดูล (แฟลช)** | 2 ช่องที่ผนังบน ตรง x ≈ 23.1 / 34.5 (ต้องวัดใหม่) + ป้ายนูน `SW1 OFF ก่อนเสียบ` |
| **BOOT / RST** | รู Ø3 บนฝาให้แหย่ด้วยคลิปหนีบกระดาษ (ปุ่มลึกจากผิวฝา ~9 มม.) |
| **SW1** | ร่องบนฝา + ด้ามต่อปริ้นแยกสวมก้านสวิตช์ (ก้านอยู่ลึก ~18.5 มม.) · ความยาวร่องรอค่า `sw_travel` |
| **OLED** | หน้าต่างบนฝาเท่าพื้นที่แสดงผล + 0.5 · จอยึดใต้ฝาด้วยสกรู M2 เกลียวปล่อย 4 ตัวเข้าเสาในฝา (รู Ø2.1 ระยะ 23.04 × 23.59) · ขาจอชี้ไปด้านหลัง มีที่ว่างให้หัว dupont |
| **Buzzer** | ยึดบนเสาของฐานด้วย M3 ที่รู Ø3.24 · รูเสียง Ø2 × 7 รูบนฝาเหนือตัว buzzer |
| **ระบายอากาศ** | ร่องแคบ 1.5 มม. ที่ผนังบนและล่าง (ตามทิศติดตั้ง) ไม่อยู่ในแนวมองกล้อง |
| **ขาติด** | น็อตหกเหลี่ยม 1/4"-20 ฝังในฐาน **ไม่วางใต้เสาอากาศ** (ศูนย์กลางกล่องตรงกับแนวเสาอากาศพอดี จึงเลื่อนไปใต้ส่วนบนโมดูลหรือส่วนต่อขยาย) |
| **วัสดุ** | PETG หรือ ASA ดำทึบ · ผนังรอบ IR ≥ 2 มม. · เผื่อสวม 0.3 มม. |
| **อะไหล่ต้องซื้อ** | น็อต M3 × ~30 มม. 4 ตัว + × ~8 มม. 2 ตัว · heat-set insert M3 6 ตัว · สกรู M2 × 5 เกลียวปล่อย 4 ตัว · น็อตหกเหลี่ยม 1/4"-20 1 ตัว · แท่งอะคริลิก Ø3 (ถ้าใช้) |

## ก่อนส่งปริ้นต้องมี
1. ค่าที่ต้องวัดใหม่ลำดับ 1–3, 6–8 ใน `DESIGN_INPUTS.md` (วัดบน v1 ได้) — สคริปต์ CAD เขียนได้ก่อน ค่าทุกตัวเป็นพารามิเตอร์ แต่ **STL ตัวจริงออกหลังได้ค่าวัดเท่านั้น**
2. ทิศหมุนกล่องจากภาพสด rot 0
3. ลองปริ้นทดลองหนึ่งรอบ (PLA ได้) เช็คการสวมก่อนสั่ง PETG/ASA
