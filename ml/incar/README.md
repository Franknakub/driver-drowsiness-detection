# ทดสอบในรถ (ก่อนตัดสินใจ fine-tune)

วัดว่า firmware ตัวปัจจุบัน (เกณฑ์ของเพื่อน 0.3.12-p30: P(ปิด) ≥ 0.3 = ปิด · เตือนเมื่อหลับตา 2 วิ) ใช้ได้จริงในรถไหม
ด้วยผลจากบอร์ดเอง (`/api/status`) ไม่ใช่การจำลอง แล้วค่อยตัดสินว่าต้อง fine-tune โมเดลตาหรือไม่

| ไฟล์ | หน้าที่ |
|---|---|
| `cartest.py` | พูดบอกท่าทีละช่วง อ่าน `/api/status` ~5 ครั้ง/วิ เก็บภาพตาจาก `/eyes.raw` ถ้ามี แล้วให้คะแนน |
| `score.py` | ให้คะแนนรอบที่เก็บไว้ซ้ำ: `python score.py <ชื่อรอบ>` (ไม่ใส่ชื่อ = ทุกรอบ) |
| `fake_board.py` | บอร์ดจำลองไว้ลองสคริปต์บน PC (ผลไม่มีความหมาย) |
| `common.py` | ท่าทาง (protocol), รูปแบบ `/eyes.raw`, อ่านข้อมูลรอบ |

ข้อมูลอยู่ที่ `ml/data/incar/<ชื่อรอบ>/` ซึ่งอยู่ใน `.gitignore` · **ภาพหน้า/ตาห้ามขึ้น git**

## เตรียม

1. แฟลช **0.3.13-raw** (= `main` ตอนนี้: เกณฑ์ของเพื่อน + หน้าเว็บการ์ตูน + `/eyes.raw`) จะได้ทั้งผลทดสอบและภาพไว้ fine-tune ในรอบเดียว
   ถ้าไม่อยากแฟลช ใช้ firmware ที่อยู่บนบอร์ดได้ สคริปต์จะวัดผลอย่างเดียว ไม่เก็บภาพ
2. ติดกล่องตำแหน่งจริง: กระจกหน้า ฝั่งซ้ายคนขับ ใกล้กระจกมองหลัง แถว IR อยู่บน
3. เปิดบอร์ด (ไม้จิ้มฟันดัน SW1) ต่อโน้ตบุ๊กเข้า WiFi `Drowsy-XXXX` เปิด `http://192.168.4.1` นั่งท่าขับ
   ดูภาพสดว่ามีกรอบหน้าเขียวและกรอบตาขึ้นสม่ำเสมอ ถ้าหาหน้าไม่เจอ แก้มุม/ตำแหน่งกล่องก่อน
4. โน้ตบุ๊กเปิดเสียง (สคริปต์พูดบอกท่าเป็นภาษาอังกฤษ + บี๊บ: 2 ครั้งเสียงสูง = หลับตา, 1 ครั้งเสียงต่ำ = ลืมตา)

## รอบทดสอบตอนจอด (~3.7 นาที) ⚠️ รถจอดเท่านั้น

```bash
cd ml/incar
../.venv/Scripts/python.exe cartest.py --name 2026-11-05_day_noglasses --person frank --light day --glasses none
```

- ช่วง A (2.2 นาที, ไม่มีการหลับตา): มองถนน · เหลือบมองกระจก 3 ครั้ง · ก้มดูมือถือ · กะพริบตาปกติ 40 วิ · หรี่ตา → นับ**การเตือนผิด**
- ช่วง B (1.5 นาที): หลับตา 5 วิ × 5 ครั้ง สลับลืมตา 10 วิ + หลับตา 8 วิ → นับว่า**เตือนครบไหม**และเตือนหลังหลับตากี่วินาที
- ทำตามเสียง ไม่ต้องรีบ สคริปต์ตัดช่วงเปลี่ยนท่าทิ้งเอง · กด Ctrl+C หยุดได้ ข้อมูลที่ได้ยังบันทึก

ทำซ้ำอย่างน้อย: กลางวันไม่ใส่แว่น · กลางวันใส่แว่น (ถ้าคนขับใส่) · ครึ้ม/เย็น · กลางคืน (IR บนบอร์ดอ่อน อาจหาหน้าไม่เจอ ดูประเด็นค้าง #5)

## รอบขับจริง (นับเตือนผิดต่อชั่วโมง)

```bash
../.venv/Scripts/python.exe cartest.py --protocol drive --name 2026-11-05_drive1 --person frank --light day --glasses none
```

คนขับลืมตาขับปกติ ไม่มีเสียงบอก คนนั่งข้างคุมคอม กด Ctrl+C เมื่อจบ · ทุกการเตือนในรอบนี้ถือว่าเตือนผิด (เว้นแต่ง่วงจริง ให้จดเวลาไว้)

## อ่านผลแล้วตัดสินใจ

สคริปต์พิมพ์ผลท้ายรอบและเขียน `report.json` · ตัดสินแบบนี้:

| ผล | ความหมาย | ทำต่อ |
|---|---|---|
| หลับตาเตือน 6/6 · ช่วง A เตือนผิด 0 · ขับจริงเตือนผิดน้อย | ตัวที่เพื่อนปรับใช้ได้ | **ไม่ต้อง fine-tune** สาธิตได้ |
| ไม่เตือน และขึ้น "หาหน้าไม่เจอเกิน 40%" | ปัญหาหาหน้า/มุมกล้อง | fine-tune ไม่ช่วย → แก้ตำแหน่งกล่อง/แสง |
| ไม่เตือน และขึ้น "เห็นหน้าแต่ตอบว่าตาเปิด" (P ระหว่างหลับต่ำ) | โมเดลตาพลาดกับกล้องเรา | **fine-tune** (ภาพจากรอบนี้ใช้ได้เลยถ้าแฟลช 0.3.13-raw) |
| ลืมตาอยู่แต่เตือน, P ตอนลืมตาสูงใกล้ 0.3 | เกณฑ์ 0.3 ต่ำเกิน | ลองขยับเกณฑ์ (`P_CLOSED_ON` ใน `config.h`) ก่อน fine-tune |
| เหลือบมอง 2–3 วิ แล้วขึ้น "ไม่มองถนน" | เกณฑ์ Distraction 3 วิ | ไม่เกี่ยวกับโมเดลตา ดู `DISTRACTION_MS` |

ผลจากคนเดียวยังไม่พอสรุปว่าใช้ได้กับทุกคน ถ้ามีเวลาให้เพื่อนนั่งอีกคน (ขอความยินยอมก่อนเก็บภาพ)

