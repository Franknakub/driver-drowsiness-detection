# 🔴 BLOCKER

## B1 — SW2 ใช้ tact switch มาตัดไฟหลัก (ใหม่ ร้ายแรงสุด)

**Netlist:** `VIN ; R7.1 SW2.1 USB1.A9 USB1.B9` และ `5V ; R16.1 R17.1 R18.1 R19.1 SW2.2 U1.1 U5.39 U5.40`

SW2 ต่อ**อนุกรมคั่นระหว่าง VBUS กับราง 5V** = เป็นสวิตช์เปิด/ปิดไฟทั้งบอร์ด แต่ตัวที่เลือกคือ **TS-1088-AR02016**

| ประเด็น | สเปกจริงของ TS-1088-AR02016 | ภาระจริงบนบอร์ด | ผล |
|---|---|---|---|
| ชนิดสวิตช์ | **tact switch แบบกด-ปล่อย (SPST-NO momentary)** | ต้องการค้างสถานะเปิด | ❌ **ไฟติดเฉพาะตอนกดค้างเท่านั้น บอร์ดทำงานต่อเนื่องไม่ได้** |
| กระแสหน้าสัมผัส | **50mA @ 12VDC** | โมดูล ESP32-S3 พีคตอน WiFi TX ~500mA + IR 116mA | ❌ **เกินพิกัด ~10 เท่า** → หน้าสัมผัสไหม้/เชื่อมติด |
| อายุใช้งาน | ~100,000 ครั้ง (ที่โหลด logic-level) | สวิตช์กำลัง | ❌ ลดฮวบเมื่อใช้เกินพิกัด |

แหล่งข้อมูลระบุตรงๆ ว่าเหมาะกับ *"logic-level circuits and microcontroller applications rather than direct power switching"*

**ทางแก้ (เลือกอย่างใดอย่างหนึ่ง):**
1. เปลี่ยนเป็น **slide switch / latching switch** ที่รับได้ ≥1A (เช่น SS-12D00 series) — ง่ายสุด
2. เก็บ tact switch ไว้แต่ให้ไปคุม **P-MOSFET high-side** แทน (SW2 → gate driver → MOSFET ตัดไฟ) — กระแสไหลผ่าน MOSFET ไม่ผ่านสวิตช์
3. ถ้าไม่ได้ตั้งใจให้มีสวิตช์ตัดไฟ ให้ลัด VIN↔5V ตรงๆ แล้วเอา SW2 ออก

**หมายเหตุที่ออกแบบถูกแล้ว:** `R7.1` (ตัวป้อน VDD ของ CH221K) อยู่ฝั่ง **VIN คือก่อนสวิตช์** → ชิป PD ยังมีไฟตอนสวิตช์ปิด ทำให้เจรจา PD ได้ปกติ ✅ ถูกต้อง

## ⚠️ ประเด็นเชิงกล — ต้องวัดโมดูลจริงยืนยัน

**ตัวเลขที่วัดได้จากบอร์ด:**

| จุด | พิกัด y | ระยะจาก pin ล่างสุดของ header (y = −66.04mm) |
|---|---|---|
| pin ล่างสุดของ header | −66.04mm | 0 |
| **MOUNT1** (รูขาตั้ง ⌀7.5mm) | −72.50mm | **6.46mm** |
| **SW2** | −73.80mm | **7.76mm** |
| ขอบล่างบอร์ด | −81.15mm | 15.11mm |

- header span = **48.26mm** (2×20 pin, pitch 2.54mm) แต่โมดูล ESP32-S3-CAM ยาว **67mm** → มีตัวโมดูล **18.74mm ที่ยื่นเลย pin ออกไป** (แบ่งไปหัว-ท้ายอย่างไรขึ้นกับตำแหน่ง pin บนโมดูล)

**🔺 ความเสี่ยง: ถ้าโมดูลยื่นเลย pin ล่างสุดเกิน 6.46mm ตัวโมดูลจะบังรู MOUNT1 → เสียบสกรูขาตั้งกระจกไม่ได้** และถ้าเกิน 7.76mm จะกดทับ SW2 ด้วย

หมายเหตุใน `CLAUDE.md` เคยบันทึกว่าวัดจริงแล้วโมดูลยื่นเลย header **~2mm** — ถ้าเป็น 2mm ที่ปลายล่าง ก็**ปลอดภัย** แต่ตัวเลข 67mm vs 48.26mm บอกว่ารวมสองด้านต้องยื่น 18.74mm จึงควรวัดซ้ำว่า **แต่ละด้านยื่นเท่าไหร่**

**วิธีเช็คเร็วที่สุด:** วัดจากรูพินล่างสุดของโมดูลถึงขอบล่างสุดของแผ่นโมดูล ถ้า **< 6.4mm** ผ่าน

- ด้านบน: pin บนสุด (y = −17.78mm) ห่างขอบบอร์ดบนแค่ **2.29mm** → โมดูลจะยื่นพ้นขอบบอร์ดด้านบนแน่นอน (ปกติไม่เป็นปัญหาเพราะลอยอยู่ในอากาศ แต่ต้องเผื่อพื้นที่ตอนติดตั้งจริง)

ข้อความ `USB1` ที่ (13.9, −28.1)mm อยู่ใกล้ pad `13` ของ USB1 มาก
**ความมั่นใจต่ำ** — วิธีตรวจของผมใช้ระยะจากจุดยึดข้อความ ไม่ได้คำนวณกล่องตัวอักษรจริง แนะนำซูมดูด้วยตา

# ลำดับการแก้ที่แนะนำ

1. **B1** SW2 — ตัดสินใจก่อนว่าจะเอาสวิตช์ไฟไหม (ถ้าไม่เอา ลัด VIN↔5V ง่ายสุด)
