# ตัดสินความง่วงและเตือนบน Device เอง ส่งออกแค่ตัวเลขกับ Event

การเตือนความง่วงเป็นงานด้าน safety จึงต้องทำงานได้แม้ในรถไม่มีเน็ตหรือไม่มีมือถือ เราเลยให้ ESP32-S3 ทำทั้งหาตา ตัดสิน Eye State คำนวณ Drowsiness Level และสั่ง Alert เองทั้งหมด สิ่งที่ส่งออกจาก Device มีแค่ Sample, Event และ Trip Summary ส่วนภาพดิบไม่ส่งออก ยกเว้นตอน Driver เปิดดูภาพสดหรือเก็บภาพไปทำ dataset เอง

## Considered Options

- **ส่งภาพไปประมวลผลบนมือถือหรือโน้ตบุ๊ก (MediaPipe Face Mesh + EAR)** แม่นกว่าและทำเสร็จเร็วกว่า แต่ไม่ใช้แล้ว เพราะถ้าเครื่องปลายทางหลุด การเตือนจะหายไปด้วย และ Device จะกลายเป็นแค่กล้อง WiFi ซึ่งไม่ตรงกับโจทย์วิชา Embedded

## Consequences

- ความแม่นถูกจำกัดด้วยโมเดลขนาดเล็ก (INT8) และ fps ที่ต่ำ (ราว 4–10) เกณฑ์ทุกตัวจึงนับเป็นวินาที ไม่ได้นับเป็นจำนวนเฟรม
- Device ต้องเก็บประวัติเองก่อนเสมอ ส่วน cloud เป็นแค่ปลายทางที่ซิงก์ข้อมูลไป
