# เอกสารออกแบบช่วงแรก (มิ.ย.–ส.ค. 2026)

เก็บไว้เป็นประวัติเท่านั้น **ข้อมูลหลายจุดไม่ตรงกับบอร์ดที่สั่งผลิตแล้ว** เช่น

- ใช้ไฟ 12V จากรถ + MP1584EN + AMS1117 → ของจริงใช้ power bank 5V ผ่าน USB-C
- ใช้ ESP32-S3-WROOM บัดกรีติดบอร์ด → ของจริงเสียบโมดูล ESP32-S3-CAM บน header
- มี MPU-6050 → ตัดออกแล้ว
- GPIO หลายขาไม่ตรง (เช่น I2C SCL, IR LED, LED แดง)
- อ้างถึง LINE Notify ซึ่งปิดบริการไปแล้ว
