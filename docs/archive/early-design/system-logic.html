02

📥 INPUT — ทุกตัว

📷 OV5640 Camera (5MP + AF)

Input หลัก — ถ่ายภาพใบหน้าแบบ real-time
ความละเอียด5MP (2592×1944) — crop เหลือ 96×96 px ส่ง model
Autofocus✅ โฟกัสอัตโนมัติ — ชัดแม้คนขับขยับหัว
FPS30fps (ดีกว่า OV2640 ที่ทำได้แค่ 15fps)
InterfaceDVP 8-bit parallel → ESP32-S3 GPIO
ตรวจจาก ตาเปิด (Alert) ตาหลับ (Drowsy) หาว (Yawning)
Output ที่ให้ค่า EAR (Eye Aspect Ratio) 0.0–1.0

🌗 LDR Light Sensor

Input เสริม — วัดระดับแสงในรถ
วัดอะไรความสว่างรอบตัวคนขับ (ambient light)
InterfaceADC → GPIO 3 (ADC1_CH2)
อ่านทุก500ms (ไม่ต้องเร็ว แสงเปลี่ยนช้า)
แสงน้อยADC < 300 → เปิด IR LED อัตโนมัติ
แสงพอADC ≥ 300 → ปิด IR LED ประหยัดไฟ
Output ที่ให้ BRIGHT DIM DARK

💡 IR LED Array (850nm) ×4

Input เสริมกล้อง — แก้ปัญหาแสงน้อยในรถกลางคืน
ทำงานเมื่อระดับแสง < threshold (ตรวจจาก LDR sensor)
เปิดอัตโนมัติกลางคืน / อุโมงค์ / ในจอดรถ
ผลต่อกล้องOV5640 เห็นตาชัดขึ้นแม้ไม่มีแสง
ควบคุมGPIO 25 → NPN transistor → IR LED ×4
หมายเหตุOV5640 low-light ดีกว่า OV2640 อยู่แล้ว + IR = ดีมาก

🔘 Tact Switch + Power Input

Input ควบคุม + จ่ายไฟ
กด 1 ครั้งเปิด / ปิดระบบ (toggle)
กดค้าง 3sรีเซ็ต alert + ปิดเสียง Buzzer
GPIOGPIO 34, pull-up internal, debounce 50ms
Power Input12V (รถ) → TVS → MP1584 → 5V/2A
หมายเหตุOV5640 ใช้ไฟ ~250mA (เผื่อใน power budget)
03

📤 OUTPUT — ทุกตัว

🔔 Active Buzzer 5V

Output เตือนหลัก — ปลุกคนขับทันที
ต่อยังไงGPIO 14 → MOSFET → Buzzer 5V
Level 1บีบ×2 สั้น (ตาหลับ 1.5s)
Level 2บีบ×3 ดัง (ตาหลับ 3s / PERCLOS > 80%)
Level 3ต่อเนื่อง!!! (ตาหลับ 5s ขึ้นไป)
รีเซ็ตกดปุ่มค้าง 3s หรือตาเปิดนาน > 2s

💡 LED Indicator ×2

Output แสดงสถานะระบบ
LED1 🟢ระบบพร้อม / ตื่น — ติดค้าง
LED2 🔴ตรวจพบง่วง — กะพริบตามระดับ
เปิดระบบ🟢 กะพริบ 3× แล้วติดค้าง
Level 1🔴 กะพริบช้า (0.5Hz)
Level 2-3🔴 กะพริบเร็ว (2Hz) / ติดค้าง
GPIOGPIO 26 (เขียว), GPIO 27 (แดง) + R 220Ω

🖥️ OLED Display (0.96")

Output แสดงผล real-time บนบอร์ด
InterfaceI2C → SDA GPIO 1, SCL GPIO 2 (bus แยกจากกล้อง)
แสดงผลSTATUS / EAR value / PERCLOS / เวลาที่ง่วง
หน้าจอปกติSTATUS: ALERT | EAR: 0.31 | PERCLOS: 12%
หน้าจอง่วงSTATUS: DROWSY | EAR: 0.14 | TIME: 00:03
หน้าจออันตราย⚠️ DANGER!!! | EYES CLOSED 5s

📱 WiFi Alert → Line Notify

Output เสริม — แจ้งเตือนมือถือ (Level 3 เท่านั้น)
ส่งเมื่อLevel 3 เท่านั้น (อันตราย)
ข้อความ"⚠️ DANGER! ตรวจพบง่วงมาก — เวลา 23:45"
วิธีESP32-S3 WiFi → HTTP POST → Line Notify API
ต้องการWiFi hotspot ในรถ หรือ mobile hotspot

สูตร EAR — ตัดสินว่าตาหลับไหม

// Eye Aspect Ratio (EAR) ────────────────────────────
EAR = ( ||p2−p6|| + ||p3−p5|| ) / ( 2 × ||p1−p4|| )

// p1–p6 = จุด landmark รอบดวงตา 6 จุด (จาก TinyML)
// ตาเปิด → EAR ≈ 0.25 – 0.35
// ตาหลับ → EAR < 0.20 ← threshold

if EAR < 0.20:
eye_closed_frames += 1 // นับ frame ที่หลับ
else:
eye_closed_frames = 0 // reset ทันทีที่ตาเปิด

// OV5640 30fps → 1s = 30 frames (แม่นกว่า OV2640 ที่ 15fps)
if eye_closed_frames >= 45: level = 3 // หลับ 1.5s
elif eye_closed_frames >= 90: level = 2 // หลับ 3s
elif eye_closed_frames >= 150: level = 1 // หลับ 5s

07

Multi-Signal Logic — ตรวจ 3 สัญญาณจากกล้อง

💡 ระบบนี้ใช้กล้องอย่างเดียว (ไม่มี IMU) จึงต้องดึงสัญญาณหลายตัวจากภาพเดียวกัน เพื่อลด false positive
// ดึง 3 สัญญาณจากกล้อง OV5640 ──────────────────────
ear = eye_inference() // ตาหลับไหม
blink_rate = count_blinks() // กะพริบถี่ไหม (ครั้ง/นาที)
yawn = yawn_inference() // หาวไหม

// ── สัญญาณ 1: PERCLOS (น้ำหนักมากสุด) ──────────────
if ear < 0.20:
eye_closed_frames += 1
else:
eye_closed_frames = 0

perclos = eye_closed_frames / total_frames_1min × 100

// ── สัญญาณ 2: อัตราการกะพริบ ───────────────────────
// ปกติ 15-20 ครั้ง/นาที · ง่วง > 25 ครั้ง/นาที
if blink_rate > 25: drowsy_signals += 1

// ── สัญญาณ 3: การหาว ───────────────────────────────
if yawn_count_5min >= 2: drowsy_signals += 1

// ── รวมผล ──────────────────────────────────────────
if eye_closed_frames >= 150: level = 3 // หลับ 5s = อันตราย
elif eye_closed_frames >= 90: level = 2 // หลับ 3s
elif eye_closed_frames >= 45: level = 1 // หลับ 1.5s
elif perclos > 80: level = 2 // ตาปิดเกิน 80% ของเวลา
elif drowsy_signals >= 2: level = 1 // กะพริบถี่ + หาว
else: level = 0
