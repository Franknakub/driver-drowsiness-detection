📏 Design Rules (ตามที่อาจารย์กำหนด)

🔴 อาจารย์กำหนดเข้มกว่า JLCPCB minimum
JLCPCB ทำได้ต่ำสุด 4mil (0.10mm) แต่อาจารย์เขียนโน้ตไว้ว่า 6mil = ขั้นต่ำที่ยอมรับ และ 12mil ++ = ค่าที่ควรใช้จริง
เหตุผล: track width tolerance ของโรงงานคือ ±20% — ถ้าออกแบบ 4mil อาจได้จริงแค่ 3.2mil เส้นบางเกินไป เสี่ยงขาด/กระแสไม่พอ

⚠️ กฎ Layout ที่ห้ามพลาด

Antenna Keepout — พลาดแล้ว WiFi ตายเว้นพื้นที่ใต้และรอบเสาอากาศ ESP32-S3 อย่างน้อย 3mm ห้ามมี copper pour / trace / via ทั้ง top และ bottom layer
Decoupling cap ต้องติดชิด pinC 100nF ห่างจาก VCC pin ไม่เกิน 2mm — ถ้าวางไกลจะไม่มีผลเลย
Camera DVP ความยาวใกล้เคียงกันเส้น D0–D7 + PCLK ควรยาวต่างกันไม่เกิน ±5mm กัน timing skew
GND Plane เต็ม bottom layerเท copper pour GND ทั้งชั้นล่าง + โรย via stitching ทุกๆ 5–10mm (via 0.6/0.3mm)
Power trace ใช้ Net Class POWER12V/5V/3.3V/GND ตั้งเป็น 0.80mm ผ่าน Net Class — อย่า route ด้วยค่า default
Switching loop ของ DC-DC ให้เล็กวง VIN → SW → L1 → C2 ให้สั้นที่สุด และวางห่างจาก ESP32 กับกล้อง
USB D+/D− เป็น differential pairวางขนานกัน ระยะห่างคงที่ ความยาวเท่ากัน (90Ω differential)
